# Stage 3 - Review

## Purpose and milestone

Purpose: use direct feedback on the rendered private Sites preview to make the prototype feel intentional, useful, and ready to share internally.

Milestone: the attendee has either left and resolved browser annotations or explicitly approved the prototype as-is, then reviewed the updated workspace-private page.

## Review in the browser

Use the stage label **Web Adventure - Stage 3 of 4: Review**. Keep the workspace-private Sites preview open in the built-in browser side panel.

Ask the attendee to review the page for clarity, content, visual hierarchy, spacing, readability, mobile behavior, accessibility, and whether the primary action is obvious.

When browser annotations are available, guide them precisely:

1. Turn on annotation mode in the built-in browser.
2. Click an element or drag across the part of the page they want to change.
3. Write a specific comment describing the problem and desired result, then save it.
4. Repeat for other focused changes.
5. Return to chat and ask ChatGPT to address the saved browser comments.

After changes are made, update the attendee's existing private Sites preview, then reopen or refresh it in the side browser and inspect the rendered result. Keep the scope narrow: one review pass can contain multiple focused comments, but do not turn late feedback into a new application.

If annotation mode is unavailable, collect the same feedback in chat with section names and clear desired outcomes. Never say an annotation was saved or addressed without verification.

## Stage close

Summarize the annotations or feedback, what changed, what was verified, and any remaining limitation. Ask the attendee to approve the finished page. When they approve it, announce Stage 3 complete and remind them to collect the Review stamp.

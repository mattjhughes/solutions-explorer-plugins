# Site Brief Blueprint

Use this as a configurable starting point, not a rigid form.

## Required decisions

- **Audience:** one clear group of visitors
- **Concept:** what the page is about, in one sentence
- **Primary purpose:** the one thing a visitor should understand or do
- **Scope:** one page with three to five sections
- **Content:** the information, images, or links already available
- **Visual direction:** a few words describing the intended feeling

## Useful one-page structure

1. A clear opening: title, short explanation, and primary action
2. The key information or experience
3. Supporting detail in two to four focused sections
4. A clear close or next action

## Keep the first version achievable

The first version should not require login, user accounts, a database, payments, integrations, or a broad multi-page information architecture. If the attendee wants one of those later, record it as a future idea rather than silently expanding the event build.
